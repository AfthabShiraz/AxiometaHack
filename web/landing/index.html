The problem

Remote inspection, search-and-rescue drills, and accessibility all need presence in places people can’t safely go — but joysticks and 2D streams feel like remote control, not being there.

The solution

A 4WD FPV rover with a head-linked pan-tilt camera, wrist IMU driving, and a Meta Quest WebXR passthrough view so you move the robot the way you move yourself.

Headset teleop

Passthrough + robot POV. Look around; the gimbal follows. Drive with the glove.

Rescue missions

Obstacle courses, victim markers, live minimap — one interface, many scenarios.

Companion mode

Anime eyes, emotion matrix, and (stretch) Anthropic + ElevenLabs personality.
